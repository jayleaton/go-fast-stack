# Known vulnerabilities `make vulncheck` lets through (scripts/vulncheck).
#
# Only for an advisory with no fix, or none its consumer can take, that this
# repository cannot reach. Anything with a usable fix gets bumped instead.
# One entry per line:
#
#   <id> <package> <review-by YYYY-MM-DD> <reason>
#
# <id> is the GO- id for Go (govulncheck), the GHSA id for npm (pnpm audit).
# <package> is the Go module or npm package the advisory names.
# Past its review date an entry fails the check: re-check the advisory and the
# reachability, then move the date (at most 3 months) or delete the entry.
# An entry that matches nothing fails too: delete it. A Go entry whose symbol
# our code calls fails even when listed.
